# Verity L2 Edge

**Introduction**

Verity is available in one of two different versions: **L2 Edge** and **Data Center**.  The **L2 Edge** solution is historically referred to as **Enterprise**.  

As the two versions evolve, the **L2 Edge** documentation covers only its deviations from the **Data Center** documentation, deferring to it where applicable.

The Verity L2 Edge system is designed to interface with a Campus Architecture. The network topology is auto-discovered by the Verity software. Additionally, no manual configuration is required for interconnects between White Box devices — TORs, AGGs, and ONTs. This allows for simple replacement of devices and movement of port connections in the event of hardware component or connection failures. Black Box devices that support LLDP are also automatically discoverable.
