# Dell OME Integration

Verity can connect to a Dell OME server to gather telemetry and display server information in the automated dashboards.  Verity routinely polls the OME API with Read-Only access and places the inventory and telemetry into the Verity datastore.

!!! Note

    Servers added to Dell OME MUST have Dell OME Enterprise Advanced licenses in order to provide the necessary telemetry to Verity.

## Configure Dell OME Server Integration

1. Go to Admin > Dell OME.
1. Add a new server and provide the necessary credentials to reach the server.
1. Dell OME dashboard will be created in a few minutes.
1. Navigate to the the dashboard and select the server Host OS name from the dropdown list at the top.
