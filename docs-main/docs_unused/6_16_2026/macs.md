# MACs

**Reports → Macs** (**MAC Address Workbench**) provides administrators with a comprehensive view to inspect MAC addresses across the entire system.

![](media/macs_6_5_window.png)

The **Mac Address Workbench** lets you search device by mac address. Clicking the **Search** button without specifying a mac address displays all devices (![](media/macs_6_5_window_search.png){:class="pop"}).

![](media/mac_list.png)


From within a list of devices, clicking (![](media/buttons/6.5/macs_open_tab.png){:class="btn"}) opens a new tab to search on the corresponding mac address (![](media/macs_click_at_symbol_6_5.png){:class="pop"})
