Valid characters for parameter names within Verity include:

| Character(s) | Description |
| - | - |
| 0-9 | Numbers | 
| a-z | Lower Case letters |
| A-Z | Upper Case letters |
| _ | Underscore - (note that this character is not allowed for SONiC hostnames which are set using Verity Switchpoint name)|
| . | Period |
| + | Plus - (note that this character is not allowed for SONiC hostnames which are set using Verity Switchpoint name) |
| - | Hyphen |
