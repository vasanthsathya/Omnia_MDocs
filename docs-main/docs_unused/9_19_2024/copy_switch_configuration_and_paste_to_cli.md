# Copy Switch Configuration and Paste to CLI

Verity for Edge (Enterprise) and Verity for Cloud (Data Centers) Software Version 6.2.0+

This feature allows you to copy switch configuration data and paste it into the switch CLI. To use this feature, follow these instructions:

1.  Zoom in to the top portion of a switch with the settings you want to copy.

![switch_settings](media/switch_settings.png)

2.  Click the View Switch Configuration button ![](media/5c676c178122ba3d1574f7b76b035124.png){:class="btn"}.

![A screen shot of a graph Description automatically generated](media/f5c4e745f00e9ee6516600443c02f703.png)

3.  In the Configuration window, choose the 'Type' menu to select the type of data you want to copy.

![A screenshot of a computer Description automatically generated](media/97c16f6d674fd5862c053eef07b47ac8.png)

4. Click the Copy to Clipboard button ![](media/405bb21dbe614cf369943e9421de03e6.png){:class="btn"}. This button copies the switch data to the browser's clipboard. If you change the Type menu setting and wish to copy the new data, you will need to click the copy button again to capture the updated information.



![A screenshot of a computer Description automatically generated](media/cf76fbe317ebea9cc7e962f5d08aae06.png)

5.  Double click the CLI window (circled in the diagram below) and click the Open for Edit button ![](media/6bf734f87ac7c89fefba9a4e770b5613.png){:class="btn"}
6.  Use the Paste command, (Ctrl-P) to paste the previously copied content to the CLI window.

![A screenshot of a computer Description automatically generated](media/cli_window.png)



Click the Checkmark button to save the CLI Commands ![](media/df5487ae8dd5c74ca50681aaaaf89d8f.png){:class="btn"}.
