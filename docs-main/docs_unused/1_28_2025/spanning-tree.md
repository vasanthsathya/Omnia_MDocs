# Spanning Tree

**Spanning Tree** is a protocol used to prevent loops in Ethernet networks.

To access the **Spanning Tree Type** settings go to **Topology/Site Settings**.




![](media/spanning_tree_window.png)

To the right of the **Spanning Tree Type** form is the the **Spanning Tree Type Wizard **. This is a tool to help you choose the Spanning Tree Protocol (STP) types for each device. To use the Spanning Tree Type Wizard click the icon ![](media/buttons/6.2/button_wizard.png){:class="btn"}.



This graph demonstrates which switches support STP (Spanning Tree Protocol). In the final line, the recommendation(s) will be displayed.
